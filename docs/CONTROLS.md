# Controls

## Exploration

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | Z / S / Q / D or arrow keys | Left stick |
| Walk (slower movement) | Hold Shift | — |
| Interact / confirm | Enter | A button |
| Cancel / back | X | B button |
| Previous page | Page Up | L1 / Left shoulder |
| Next page | Page Down | R1 / Right shoulder |

Keyboard layout is based on physical key position, so AZERTY and QWERTY both work without remapping.

## Debug

| Key | Effect |
|---|---|
| F3 | Toggle collision and warp-trigger overlay |
| F8 | Start a debug battle session (developer mode only) |
